# Financial-Engineering-Project

README
This project explores how data, statistics, and machine learning can be used to build a smarter trading strategy. We focused on SPY, an exchange-traded fund (ETF) that tracks the S&P 500 index—representing the performance of 500 large U.S. companies. Our system analyzes early market behavior to decide when to buy or sell options contracts. The strategy, called the Open Range Breakout, monitors the first 15 minutes of the trading day to detect strong price movements while avoiding early volatility. We simulated trades using real historical data and evaluated performance using key metrics like return, win rate, and risk exposure. To improve decision-making, we trained machine learning models to predict short-term price changes based on technical indicators. We made simplified assumptions, such as perfect trade execution and stable market conditions, to focus on core strategy development. Our results show that while the strategy can perform well in specific scenarios, it carries risks and depends heavily on accurate modeling. This project demonstrates how financial trading can be approached using engineering and data science methods. All code, visualizations, and results are available through our GitHub repository.

We worked on this over the course of the Spring 2025 semester as part of the Industrial and Systems Engineering Ambassador's Introduction to Research project.
